# 50 — Endgame recipes (diary → teachings → media → journey)
*Status: PROPOSED. Endgame recipes R1-R9: spec, unbuilt by design, owner-gated. (2026-11-14.)*

Nine flavors of one shape: **private source (consent) → compile (verbatim +
claims) → sharpen (L3/L4) → verify (audit/pushback) → human gates
(review/sign) → render (audio/video/book) → link (journey/bibliography).**

Standing invariants (non-negotiable): diary is PRIVATE (consent per use,
revocable, no auto-publish of personal material ever); every sourced claim
resolves or it doesn't ship; machine proposes, human disposes; tiers on
everything.

## R1 — Diary → personal essay (read)

Diary entries (consent) → teacher retrieve-first → essay_compile (diary voice
verbatim + banked claims + tiers) → L3/L4 → audit/pushback → review → signed
text. Owner: nibbanahelp (diary) + essay pipeline. **Pipeline exists; consent
path is owner-gated, not enabled by default.**

## R2 — Essay → teaching audio (listen)

Signed essay → audio render (TTS/pack with receipts; reuse R2 svread-audio and
aoc patterns, don't rebuild). Gate: audio matches signed text (no improvised
lines); human listens once.

## R3 — Essay → video (own/publish)

Knowledge dossier (aim + textual orientation + visual rules) → factory render →
sealed mp4 (GOLDEN-style gates) → owner holds the file + publishes at will.

## R4 — Journey-linked publishing

Video/essay ↔ journey ledger entries, explicit references (`journey:<id>`),
never embeds of private entries. Journey go still owed (owner).

## R5 — Parables / C2 registers (roadman et al.)

Register renders (genz/roadman/plain) OVER compiled claims, never instead of
them: prompt + model/date + paragraph→claim maps (C2 contract). Owner lanes
hold voice direction.

## R6 — Kids books (highest bar)

Compiled claims → simplified register → human reads EVERY line aloud →
age-appropriate review → book pipeline. No invented content, no generated
morals, no unreviewed simplifications. The bar is higher than Scholar: children
can't check our work.

## R7 — Diary book: year review of hardships

Diary year (consent, scoped) → tension arcs (open→loosening→resolved,
human-flipped only) → book pipeline (TEXT-GATE per entry) → publish. Year
boundary explicit; unresolved tensions stay unresolved in print (honest endings
only).

## R8 — Poem book from your words

Diary lines → verbatim selection (arrangement is the only craft; no generated
lines, no paraphrase, compiler law) → L3/L4 craft passes → book. Your words or
nothing.

## R9 — Short movies (NOT YET)

Gated on model quality (bar set by owner when proposed; current models do not
qualify — no build, no tests, no placeholders). On qualification: packs →
render → sealed mp4, same gates as R3.

## V1 scope decision (no feature creep)

R1–R9 stand as **spec, not V1 blockers**. The essay pipeline (compile → check →
pushback) is built and tested; consent paths stay owner-gated. If V1 must
include one recipe end-to-end, the cheapest honest one is R1 with a scoped
consent — but that needs the owner's consent decision, not more code.
